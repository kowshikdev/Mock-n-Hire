# Single merged backend -- both FastAPI apps (recruiter ranking in
# api_service.py, candidate/interview routes in student/) now run as one
# process/one Railway service. Requires Python 3.11+ (raised from 3.10 when
# the prep agent's `deepagents` dependency was added -- it hard-requires
# >=3.11. Pinned via api/.python-version, which Railway's Railpack builder
# reads directly.
#
# Cleaned up from the originals: removed `python==3.10.11` (not a pip package),
# `langchain`/`faiss-cpu` (imported nowhere), `keras`/`tf-keras`/`tensorflow`
# (only the never-loaded emotion model used those -- dropped), `jwt` (auth now
# goes through supabase.auth, not manual JWT decode), the duplicate/wrong
# `dotenv` package, `zipfile36` (stdlib zipfile is used), unused
# google-auth/tqdm/requests entries, and (from student/requirements.txt)
# `moviepy` (imported nowhere).

fastapi
uvicorn

python-dotenv
supabase
pydantic

openai                    # pointed at Groq's OpenAI-compatible endpoint (see process_resumes.py)

sentence-transformers     # loaded in process_resumes.py (embedding-based ranking is Phase 1 / #9)

# Resume text extraction, shared by both sides via resume_text.py. pdfminer.six
# was dropped when the recruiter path moved onto the same extractor: PyMuPDF
# already handled PDFs on the candidate side and, unlike pdfminer, exposes
# block geometry, which is what makes reading order recoverable on two-column
# resumes.
pymupdf                   # PDF extraction (imports as `fitz`)
python-docx               # DOCX extraction

# opencv-python-headless was here for stress.py's OpenCV video-duration probe

# started returning audio duration directly from the transcription call
# already being made -- see student/core/pace.py.
